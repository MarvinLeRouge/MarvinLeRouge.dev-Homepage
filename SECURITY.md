# Security Policy

## Supported versions

Only the site currently deployed at [marvinlerouge.dev](https://marvinlerouge.dev), built from the latest state of the `main` branch, is supported.

## Reporting a vulnerability

If you find a security issue (for example a misconfigured header, an exposed file, or a vulnerable dependency), please report it privately rather than opening a public issue:

- Use GitHub's [private vulnerability reporting](https://github.com/MarvinLeRouge/MarvinLeRouge.dev-Website/security/advisories/new) for this repository, or
- Contact the maintainer directly by email (see the GitHub profile for contact details).

Please include the affected URL and steps to reproduce.

## Scope notes

The site is fully static: no backend, no database, no user accounts, no form submissions and no audience measurement.
