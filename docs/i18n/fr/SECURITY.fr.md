# Politique de sécurité

## Versions supportées

Seul le site actuellement déployé sur [marvinlerouge.dev](https://marvinlerouge.dev), construit à partir de l'état courant de la branche `main`, est supporté.

## Signaler une vulnérabilité

Si vous trouvez un problème de sécurité (par exemple un en-tête mal configuré, un fichier exposé ou une dépendance vulnérable), merci de le signaler en privé plutôt que par une issue publique :

- via le [signalement privé de vulnérabilité](https://github.com/MarvinLeRouge/MarvinLeRouge.dev-Website/security/advisories/new) de GitHub pour ce dépôt, ou
- en contactant directement le mainteneur par email (voir le profil GitHub pour les coordonnées).

Merci d'indiquer l'URL concernée et les étapes pour reproduire le problème.

## Périmètre

Le site est entièrement statique : pas de backend, pas de base de données, pas de comptes utilisateurs, pas de formulaire et pas de mesure d'audience.
